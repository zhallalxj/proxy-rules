# proxy-rules

Personal Shadowrocket routing rules.

## Recommended single subscription

[Meta.list](https://raw.githubusercontent.com/zhallalxj/proxy-rules/main/Meta.list) combines Facebook, Instagram, WhatsApp, Meta AI, Muse and Threads rules from blackmatrix7, Lxp1986, MetaCubeX and local additions. It preserves Facebook IP/ASN rules and deduplicates identical rules. Shared Stripe/Mapbox/MapTiler rules inherited from Lxp1986 are also included.

Use this list instead of separate Facebook and Muse subscriptions if they share one proxy policy. Legacy Muse.list and Muse-Supplement.list remain available. Edit Muse-Custom.list for local additions. GitHub Actions syncs daily and supports manual runs.

Sources: [blackmatrix7](https://github.com/blackmatrix7/ios_rule_script), [Lxp1986](https://github.com/Lxp1986/rules-and-scripts), [MetaCubeX](https://github.com/MetaCubeX/meta-rules-dat).
